# 🌍 WANDERWISE (The Budget Travel Optimizer)

A smart web application that helps you plan budget-friendly trips with AI-powered recommendations and comprehensive travel tools.

## ⚠️ IMPORTANT: Setup Required

**Before using this app, you MUST configure your Groq API key:**

1. Visit [https://console.groq.com/keys](https://console.groq.com/keys)
2. Sign up for a **FREE** account (no credit card required)
3. Generate a new API key
4. Open `app.js` file (line 3)
5. Replace `YOUR_API_KEY_HERE` with your actual API key:
   ```javascript
   const GROQ_API_KEY = "your-actual-api-key-here";
   ```
6. Save the file and refresh your browser

**Without a valid API key, the travel plan generator will not work!**

## ✨ Features

- **AI Travel Planning** - Generate personalized travel plans using AI
- **Budget Breakdown** - Visual budget analysis with interactive charts
- **Currency Converter** - Real-time currency exchange rates
- **Weather Forecast** - 5-day weather predictions for your destination
- **Flight Estimator** - Estimate flight costs and get booking tips
- **Destination Comparison** - Compare two destinations side-by-side
- **Travel Checklist** - Organized packing and document checklist
- **Expense Tracker** - Track spending and monitor your budget
- **Save & Load Plans** - Save your travel plans for later
- **Share Options** - Share plans on social media
- **Download Report** - Export your plan as a Word document
- **Dark/Light Theme** - Switch between themes for comfortable viewing

## 🚀 How to Use

1. **Get your Groq API Key** (Free):
   - Visit [Groq Console](https://console.groq.com/keys)
   - Sign up for a free account
   - Generate a new API key
   - Open `app.js` and replace `YOUR_API_KEY_HERE` with your actual API key

2. Open `index.html` in your web browser
3. Enter your destination, budget, duration, and travel type
4. Click "Generate Plan" to get AI-powered recommendations
5. Use the floating menu to access additional tools
6. Toggle between light and dark themes using the sun/moon icon
